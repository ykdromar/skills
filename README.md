# Agent Skills

This repository stores reusable skills for AI agents. Each skill lives in its own top-level folder and has a `SKILL.md` file containing its instructions.

## Skills

- [Organized Changes](organized-changes/SKILL.md) — make project changes in clear, reviewable feature branches and work units.
- [Classify Code Changes](classify-code-changes/SKILL.md) — classify proposed or implemented changes as critical or non-critical and explain developer review needs.
- [Review Code Changes](review-code-changes/SKILL.md) — review code diffs, report evidence-based findings, and route critical or architectural changes for developer review.

## Organization

Add skills as top-level folders. Group related skills into folders only when the collection grows enough to benefit from categories such as a technology stack or use case. Keep skill instructions independent of a particular AI agent or coding environment unless the skill explicitly requires one.
